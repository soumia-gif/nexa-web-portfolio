====================================================================
DOSSIER POUR VOS CAPTURES D'ÉCRAN RÉELLES DE PROJETS
====================================================================

Pour ajouter vos futures captures d'écran dans votre portfolio :

1. Déposez vos images dans ce dossier (ex: public/projects/) :
   - adrenaline.png (pour le projet Adrenaline Salle)
   - mes-recettes.png (pour le projet Mes Recettes)
   - meteo.png (pour le projet Météo)

2. Ouvrez le fichier src/data/projectsData.ts et remplacez :
   image: '' 
   par :
   image: '/projects/adrenaline.png' (ou le nom de votre fichier).

Les cartes de projets afficheront automatiquement vos vraies images !
